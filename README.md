# Emmanuel Maravilha — carrousel de figurines

Page d'accueil en carrousel de figurines, construite avec React, TypeScript, Vite, Tailwind CSS et lucide-react.

## Lancer en local

```bash
pnpm install
pnpm dev
```

## Build de production

```bash
pnpm build
pnpm preview
```

Les images des figurines sont dans `src/assets/perso/` (WebP). Une connexion internet est nécessaire pour charger les Google Fonts.
